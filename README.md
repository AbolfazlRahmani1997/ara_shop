# ARA Cursor UI

This folder contains:
- index.html — static visual reference
- styles.css — responsive reference styles
- CURSOR_PROMPT.md — ready-to-paste Cursor implementation prompt

Recommended workflow:
1. Open your real Next.js project in Cursor.
2. Put this folder in the project or attach the files as reference.
3. Paste CURSOR_PROMPT.md into Cursor Agent.
4. Tell Cursor to implement the page in your existing project.
5. Ask it to preserve your existing architecture and only create/modify the landing components.
